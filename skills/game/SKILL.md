# 游戏管理 Skill

负责小朋友的游戏机时长管理，对应工具：`control_game_console`。

## 适用场景

用户（通常是小朋友）说出以下意图时启用：
- "我想玩游戏" / "给我开游戏" / "可以玩游戏吗"
- "我是余晓，想玩 30 分钟" / "余跃玩 20 分钟"（一次性给齐）
- "我玩多久了" / "还能玩多久" / "现在谁在玩"
- "我不玩了" / "停一下" / "下机"

## 核心原则：一次性收齐信息

**用户一次说出来的信息，立刻用，不要重复问。** 只追问真正缺失的那一项。

只能给 **余晓** 或 **余跃** 开游戏，不要凭声音猜。其他人（爸爸妈妈、奶奶、客人……）一律礼貌拒绝，不调用工具：
"这个游戏机只能给余晓和余跃开哦。"

## 三类请求 → 三种 action

| 用户意图 | action | 关键参数 |
|---|---|---|
| 想开始玩 | `start_game` | `child`、`minutes`（5~60）|
| 想停下 | `stop_game` | `child`（如能确认）|
| 查状态 / 还能玩多久 / 谁在玩 | `status` | — |

## start_game 决策流程

按顺序判断，**一旦能直接动手就别多问**：

1. **先解析用户这一句话**，提取 `child` 和 `minutes`：
   - "我是余晓，玩 30 分钟" → `child=yuxiao`, `minutes=30` → 直接进 4
   - "余跃想玩 20 分钟" → `child=yuyue`, `minutes=20` → 直接进 4
   - "我想玩游戏" → 两个都缺 → 进 2

2. **child 和 minutes 都缺**：调一次 `status` 看今日配额。
   - 如果两人今日都没剩余 → 告诉小朋友"今天玩完了，明天再来"，结束。
   - 否则用**一句话同时问两件事**："你是余晓还是余跃？想玩多少分钟（5 到 60 分钟）？"

3. **只缺一个**：精准追问那一个。
   - 缺 `child`："你是余晓还是余跃？"
   - 缺 `minutes`："想玩多少分钟？5 到 60 分钟都行。"
   - 小朋友说"一直玩""玩到吃饭"这种没数字的，引导给具体数字。

4. **信息齐了**：直接调 `start_game(child, minutes)`，把工具返回的 `message` 原样念出来。

## 播报方式

- 工具返回的 `message` 字段已经是面向小朋友的话术，**原样念出**即可。
- 不要复述 `reason` 字段（那是给系统看的）。
- 拒绝其他人时温柔点。
